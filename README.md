# 6001CEM_PurviTulcidas_ID13704610_MLalgorithms
This is for the project dissertation, the files are dissertation1 (Netflix related), dissertation2 (Amazon Prime Video related)

Dataset URLs: 
**https://www.kaggle.com/datasets/shivamb/netflix-shows**

**https://www.kaggle.com/datasets/shivamb/amazon-prime-movies-and-tv-shows**

The files contains 3 ML algorithms and each has 3 user cases (user preference recommendations) implemented and these ML algorithms were analysed with classification report and RMSE and MAE
It contains the process of data acquisition, data exploration, data pre-processing/cleaning, data analysis/evaluation, training and testing data, unscaling for heatmap/correlation matrix, hypertuning using Gridsearch, ROC curve comparison and Precision-Recall Curve Comparison (Model evaluation)
